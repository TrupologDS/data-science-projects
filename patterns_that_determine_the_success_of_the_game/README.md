# Video Game Success Pattern Analysis

## Overview

This project analyzes historical video game sales data for an online game store. The goal is to identify patterns that distinguish commercially successful games and use them to support planning for future marketing campaigns.

## Data

The dataset contains information about released games in the `games` table.

### Features

- `Name`: game title
- `Platform`: gaming platform
- `Year_of_Release`: release year
- `Genre`: game genre
- `NA_sales`: sales in North America, in millions of copies
- `EU_sales`: sales in Europe, in millions of copies
- `JP_sales`: sales in Japan, in millions of copies
- `Other_sales`: sales in other regions, in millions of copies
- `Critic_Score`: critic score, up to 100
- `User_Score`: user score, up to 10
- `Rating`: ESRB age rating

## Objective

Identify factors associated with video game success in order to evaluate potentially popular products and plan advertising campaigns.

## Tools and Skills

Python, pandas, NumPy, SciPy, Matplotlib, exploratory data analysis, hypothesis testing, data visualization.

## Result

The analysis showed that the largest number of games was released in 2008-2009 and that an average platform lifecycle is about ten years. Sales leaders and genre/platform patterns were identified, supporting conclusions about which games were more likely to be profitable.
