# Customer Age Prediction from Images

## Overview

This computer vision project trains a neural network for a retail chain that wants to estimate customer age from photos. The system can support age-group analytics and help monitor age-restricted purchases.

## Data

The `labels` table contains:

- `file_name`: path to the image file
- `real_age`: target age label

## Objective

Predict a person's approximate age from a photograph.

## Tools and Skills

Python, TensorFlow, Keras, ResNet50, image preprocessing, convolutional neural networks.

## Result

The project analyzed the age distribution and inspected sample images before training a neural network for age prediction. The final model achieved a satisfactory result on the test set.
